# ☕ CafeOS

> 카페 운영의 모든 흐름을 하나의 시스템으로 연결하다.

**주문 · 메뉴 · 레시피 · 재고 · 직원 · 매출 · AI 운영 분석**

[ 🎬 Demo ]  [ 🚀 Live ]  [ 💻 GitHub ]

---

## 📌 Project

CafeOS는 카페 매장의 운영 데이터를 통합 관리하는
매장 운영 관리 시스템입니다.

단순 CRUD를 넘어

주문
 ↓
레시피
 ↓
재고 자동 차감
 ↓
재고 사용량 분석
 ↓
소진 예측
 ↓
AI 운영 분석

으로 이어지는 실제 매장 운영 흐름을 구현했습니다.

## ✨ Key Features

### 🛒 주문 관리
- 주문 생성 및 상태 관리
- 주문 상품 관리
- 주문 완료 데이터 기반 매출 집계

### 📦 재고 관리
- 재료별 재고 관리
- 최소 재고 설정
- 주문 완료 시 레시피 기반 자동 차감
- 최근 사용량 기반 재고 소진 예측

### 📊 매출 분석
- 일/월별 매출
- 인기 메뉴
- 카테고리별 매출
- 평균 주문 금액

### 🤖 AI 운영 분석
- 매출 분석
- 메뉴 분석
- 재고 분석
- 인력 운영 분석
- 운영 위험 분석
- 운영 개선 제안

### 👥 직원 관리
- 직원 등록/수정/삭제
- OWNER / MANAGER / STAFF 권한
- 근태 및 업무 관리
